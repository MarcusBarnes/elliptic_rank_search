# Contributing

Contributions should preserve the project's proof-status discipline.

- Distinguish heuristic evidence, exact computation, conditional results, and
  certified mathematical claims.
- Include reproducible commands or small fixtures for bugs and new workflows.
- Keep generated candidate lists, analyzed outputs, logs, and large benchmark
  files out of Git unless they are deliberately curated public fixtures.
- Prefer focused changes with tests for exact arithmetic, parser behavior, and
  small deterministic workflows.
- Do not present PARI estimates, numerical height ranks, local scores, or
  visible-point counts as certified Mordell-Weil rank lower bounds.
